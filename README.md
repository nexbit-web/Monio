# Monio — учёт доходов и расходов

Личная CRM для денег и Telegram-бот, через который траты записываются за пару секунд.

- **Бот:** пишешь `250 продукты`, `кофе 65`, `вчера такси 180`, `+30000 зарплата`, `250 обед нал` —
  сумма, категория, счёт и дата распознаются сами. Не узнал слово — предложит кнопки и запомнит выбор.
  Интерфейс бота — на украинском, понимает и украинский, и русский. Управление — клавиатурой внизу
  чата (все команды — в «📋 Команди»), кнопки «Меню» слева от поля ввода нет.
- **CRM:** обзор месяца со сравнением к прошлому, расходы по категориям и лимиты, лента операций с
  фильтрами и выгрузкой в CSV, аналитика «категория × месяц», счета и переводы между ними.

Стек: SvelteKit 2 · Svelte 5 · Prisma 7 · Postgres (Neon) · grammY · Tailwind + shadcn-svelte · Vercel.
Суммы хранятся в копейках, границы дня и месяца считаются в часовом поясе пользователя (по умолчанию Киев).

## Деплой на Vercel

База уже в облаке (Neon, Франкфурт), функции Vercel настроены на тот же регион — `fra1`
(`vite.config.ts`).

1. **Импорт проекта.** vercel.com → Add New → Project → репозиторий. Framework — SvelteKit
   (определится сам), команды сборки не трогай: `npm run build` = `prisma generate && vite build`.
2. **Переменные окружения** (Settings → Environment Variables, для Production):

   | Переменная                | Значение                                                              |
   | ------------------------- | --------------------------------------------------------------------- |
   | `DATABASE_URL`            | строка Neon **с `-pooler`** — как в `.env`                            |
   | `TELEGRAM_BOT_TOKEN`      | токен бота из `.env`                                                  |
   | `TELEGRAM_WEBHOOK_SECRET` | случайная строка 32+ символов `A-Z a-z 0-9 _ -` — та же, что в `.env` |

   `DIRECT_URL` на Vercel не нужен — он только для миграций с твоего компьютера.
   `ALLOW_REGISTRATION` не задавай: регистрация закрыта, пока в базе есть аккаунт.

3. **Deploy.** Дождись адреса вида `https://monio-xxx.vercel.app`.
4. **Бот на вебхук** — с компьютера, один раз:

   ```sh
   # останови локального бота (Ctrl+C), если он запущен
   npm run bot:webhook -- https://monio-xxx.vercel.app
   ```

   Теперь Telegram шлёт сообщения на `/api/telegram`, и бот работает, даже когда компьютер выключен.
   `npm run bot` после этого откажется запускаться, чтобы случайно не отключить вебхук
   (`npm run bot -- --force` — если правда нужно вернуться на локального бота).

5. **Проверка.** Открой адрес, войди, напиши боту `250 кофе` — запись должна появиться в CRM.

Миграции схемы на Vercel не запускаются — после правки `prisma/schema.prisma` выполни с компьютера
`npm run db:deploy` (идёт по `DIRECT_URL`).

## Локальная разработка

```sh
npm install
cp .env.example .env        # вписать DATABASE_URL и DIRECT_URL (тот же адрес без «-pooler»)
npm run db:deploy           # создать таблицы в пустой базе
npm run dev                 # CRM на http://localhost:5173
npm run bot                 # бот в режиме long polling — пока на вебхук не переключён
```

Первый аккаунт создаётся через `/register`, пока база пустая; дальше регистрация закрыта.
Привязка бота: **Настройки → Telegram-бот → Подключить** — ссылка одноразовая, живёт 15 минут.

## Безопасность

- Вход: пароль в scrypt, сессия — случайный токен (в базе только его хэш), cookie `httpOnly`, `Secure`,
  `SameSite=Lax`; 5 неудачных попыток по почте — пауза 15 минут.
- Формы и действия принимаются только со своих страниц; страницу нельзя встроить в чужой сайт;
  поисковики её не индексируют.
- Каждый запрос к данным фильтруется по владельцу — чужие счета, категории и операции недоступны.
- Бот: только личка и только привязанные Telegram; о новой привязке узнают все уже привязанные.
  Вебхук принимает обновления только с секретом и не записывает одно сообщение дважды.

## Команды

| Команда               | Что делает                                  |
| --------------------- | ------------------------------------------- |
| `npm run dev`         | CRM в режиме разработки                     |
| `npm run build`       | сборка для Vercel                           |
| `npm run bot`         | бот локально (long polling)                 |
| `npm run bot:webhook` | подключить бота к сайту на Vercel           |
| `npm run db:deploy`   | применить миграции к базе                   |
| `npm run db:migrate`  | создать новую миграцию после правки схемы   |
| `npm run db:studio`   | Prisma Studio — посмотреть таблицы          |
| `npm run check`       | проверка типов                              |
| `npm test`            | тесты: бот, парсер, категории, деньги, вход |

## Где что лежит

```
prisma/schema.prisma            модель данных: счета, категории, операции, привязки Telegram
src/lib/money.ts, date.ts       деньги в копейках и даты с учётом часового пояса (общие для CRM и бота)
src/lib/server/auth.ts          сессии, пароли, защита от подбора
src/lib/server/finance/         стартовые категории, угадывание категории, статистика, фильтры, сохранение
src/lib/server/bot/             Telegram-бот: обработчики, тексты, кнопки, хранилище; testing/ — для тестов
src/routes/                     страницы CRM; api/telegram — вебхук бота
scripts/                        запуск бота и установка вебхука
```
